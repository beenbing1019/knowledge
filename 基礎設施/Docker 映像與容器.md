# Docker 映像與容器

**映像（Docker Image）**像安裝模板；**容器（Container）**是用模板建立的執行環境。同一映像可以啟動多個容器。

| 面向 | 映像 | 容器 |
| --- | --- | --- |
| 內容 | 唯讀層、檔案與設定；不一定是單一檔案 | 映像加上可寫層與執行狀態 |
| 變更 | 要更新內容，建立新映像 | 執行期間可寫入，但刪除容器會丟失未持久化資料 |
| 用途 | 分發相同版本的應用 | 執行應用，可暫停、停止或重新啟動 |

例如同一映像啟動三個網站容器，三者各有自己的程序環境，但與主機共用作業系統核心；不是三台完整虛擬機。容器刪除後，可寫層內的上傳檔也會消失。需要保留資料時，使用資料卷（volume）或外部儲存。

## 常見使用情境

- 開發與正式環境要跑相同版本：以同一映像建立不同容器，設定與密鑰由部署環境提供，別寫進映像。
- 上傳檔案重建容器後消失：可用資料卷保存單機資料；若多節點都需存取，評估物件儲存或共用儲存，不能只依賴單台主機的 volume。
- 要更新程式：重新建置並部署映像；在執行中的容器手動改檔難以重現，也不會回寫原映像。

參考：[Docker Docs：What is a container?](https://docs.docker.com/get-started/docker-concepts/the-basics/what-is-a-container/)。
