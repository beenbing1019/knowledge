# 檔案搬移與傳輸

以下整理在本機、遠端主機及物件儲存之間搬檔的常用指令。範例中的路徑與主機都是**佔位值**，執行前先確認來源、目的地與權限；下載的壓縮檔也應視為不可信資料。

## 本機搬移與解壓縮

```bash
mv -i folder/* .
unzip -l archive.zip
unzip archive.zip -d empty-output-directory
```

`mv -i` 在目的地已有同名檔時要求確認；`folder/*` **不包含隱藏檔**，來源不存在或資料夾為空時也不能假設指令會成功。先列出來源與目的地檔案再搬移。`unzip -l` 先列出壓縮檔內容；解壓縮時選全新的空目錄，避免覆寫現有檔案，並留意壓縮檔可能包含不預期的路徑。

## 從本機複製到遠端主機

```bash
scp -r /path/to/local/folder user@host:/path/to/remote/folder
```

`-r` 遞迴複製資料夾。先確認 SSH（Secure Shell）身分驗證、目標主機指紋及目的路徑；若只傳單一檔案，不需要 `-r`。`scp` 是複製，不會刪掉本機來源；若要同步大量檔案與保留增量傳輸，可另評估 `rsync`，但須確認遠端環境與覆寫策略。

## 在 EC2 主機上下載 S3 物件

先登入有適當權限的 Amazon EC2（Elastic Compute Cloud）主機，再在該主機執行 AWS CLI（Amazon Web Services Command Line Interface）：

```bash
aws s3 cp s3://example-bucket/path/to/file.zip ./file.zip --dryrun
aws s3 cp s3://example-bucket/path/to/file.zip ./file.zip
```

第一行只預覽，第二行才下載；目標路徑是**執行指令的 EC2 主機**，不是你的筆電。執行前確認 S3（Simple Storage Service）物件路徑、主機角色權限、磁碟空間與同名檔案；不要把存取金鑰寫進筆記或命令列。

參考：[Linux man-pages：mv](https://man7.org/linux/man-pages/man1/mv.1.html)、[OpenSSH：scp](https://man.openbsd.org/scp)、[Debian：unzip](https://manpages.debian.org/stable/unzip/unzip.1.en.html)、[AWS CLI：s3 cp](https://docs.aws.amazon.com/cli/latest/reference/s3/cp.html)。
