# UDP 資料報結構

使用者資料報協定（UDP，User Datagram Protocol）把資料封裝成獨立資料報。每則資料報有 **8 位元組標頭**，後面接應用資料。

| 標頭欄位 | 大小 | 用途 |
| --- | --- | --- |
| 來源埠（Source Port） | 16 位元 | 指出傳送端的埠；某些情況可為 0 |
| 目的埠（Destination Port） | 16 位元 | 指出接收端的埠 |
| 長度（Length） | 16 位元 | 標頭加資料的長度，單位是位元組 |
| 校驗和（Checksum） | 16 位元 | 偵測傳輸中的錯誤 |

例如一則 UDP 資料報的長度欄位是 28，資料部分通常是 28 − 8 = **20 位元組**。校驗和能偵測部分傳輸錯誤，但不會自動重傳或保證真實身分；IPv4 中可選，IPv6 中一般為必需。

若影片通話遺失一則聲音資料報，UDP 不會替應用補送。應用須自己決定忽略、修補或重傳。
