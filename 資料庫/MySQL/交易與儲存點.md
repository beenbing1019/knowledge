# 交易與儲存點

交易把一組需要一起成功的操作放在同一個提交邊界。例如 A 轉 100 元給 B，不能只扣 A 而沒有加到 B。

以下用支援交易的 InnoDB 表；`BEGIN` 與 `START TRANSACTION` 擇一使用：

```sql
START TRANSACTION;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
COMMIT;
```

這是**示意**，不是完整轉帳程式。實作還須檢查餘額、更新筆數與錯誤，並處理併發。失敗時在提交前 `ROLLBACK;`。MyISAM 寫入不能靠回滾還原；部分資料定義語言（DDL，Data Definition Language）會隱含提交。

## 儲存點（Savepoint）

儲存點可只撤銷建立之後的操作，但不會自動提交或結束交易：

```sql
START TRANSACTION;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
SAVEPOINT before_credit;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
ROLLBACK TO SAVEPOINT before_credit;
ROLLBACK;
```

最後的 `ROLLBACK` 連扣款也撤銷。若此時改用 `COMMIT`，就會只扣款不入帳；真實轉帳**不可**這樣做。儲存點不是跨資料庫或外部付款系統的自動回滾工具。
