# 工程知識庫

這份知識庫整理後端工程的基礎概念、實務情境與方案取捨；各篇筆記附有適用條件與參考來源。

## 建議閱讀順序

1. 從[時間與空間複雜度](資料結構/時間與空間複雜度.md)與[陣列與鏈結串列](資料結構/陣列與鏈結串列.md)開始，建立分析操作成本的基礎，再看 Set、Map、樹與圖。
2. 讀[網路封包傳遞流程](網路/網路封包傳遞流程.md)、[TCP 與 UDP](網路/TCP%20與%20UDP.md)、[HTTP 與 HTTPS](網路/HTTP%20與%20HTTPS.md)，理解請求如何到達服務。
3. 從[MySQL 與 PostgreSQL](資料庫/MySQL%20與%20PostgreSQL.md)進入資料庫，再看[交易與儲存點](資料庫/MySQL/交易與儲存點.md)、[交易併發異常](資料庫/MySQL/交易併發異常.md)與[索引設計](資料庫/MySQL/索引設計.md)。接著讀[Redis 資料型別](資料庫/Redis/資料型別.md)與快取相關筆記。
4. 接著讀[訊息佇列基本原理](分散式系統/訊息佇列/基本原理.md)、[架構設計原則](分散式系統/架構設計原則.md)及《設計資料密集型應用》的[閱讀筆記](閱讀筆記/DDIA/02%20資料模型與查詢語言.md)，串起跨服務的資料流與取捨。
5. 想看如何把技術知識用在日常開發，接著讀[測試驅動開發](軟體開發方法論/測試驅動開發.md)與[領域驅動設計](軟體開發方法論/領域驅動設計.md)。

## 使用方式

此專案也是 Obsidian 筆記主本。主題索引使用相對路徑，在 GitHub 與 Obsidian 均可開啟；筆記間的 Obsidian 雙向連結可在 Obsidian 中瀏覽；GitHub 需從本頁主題索引進入。舊圖片保留在 `附件/` 供核對；正文已優先改用文字、表格與步驟描述，不依賴圖片才能理解。
